# stabcodes_repo

**Coordinate-free stabilizer-code circuit builder & decoder**

---

## Overview

`stabcodes_repo` builds **Stim circuits** and **Detector Error Models (DEM)** from:

- Stabilizer lists (pasted interactively or loaded from file)  
- A per-stabilizer CNOT layer schedule  

It then performs physical error rate sweeps using **Sinter + PyMatching** and plots the logical error per shot.

This repository is designed to support **coordinate-free stabilizer-code construction and decoding experiments**.

---

## Features

- Build Stim circuits from sparse or dense stabilizer descriptions  
- Generate Detector Error Models (when determinism conditions are satisfied)  
- Sweep physical error rates  
- Decode with PyMatching  
- Output metrics in JSON and CSV  
- Automatically generate logical error rate plots
